# 项目概览

## 项目背景

LumiDerm AI 起于 AI Beauty / Skin Analysis 产品概念。它先通过完整官网建立产品叙事，再用一个可本地运行的后端 MVP 验证“上传图片—生成模拟报告—保存与回看”的流程。

## 产品目标

- 以高保真官网说明产品定位、分析维度、使用场景与商业方向。
- 用结构化接口验证前后端完整闭环。
- 为未来真实模型、用户中心和云端部署保留清晰边界。

## 用户流程

用户浏览官网，进入 Skin Scan Demo，选择支持的图片；前端提交图片，后端校验并保存文件，生成模拟美容护肤报告，将报告写入 SQLite 后返回；前端展示指标、面部分区和护理方向。历史接口可分页读取记录并查询详情。

## 主要模块

- 品牌与产品叙事：Hero、ProductIntro、Technology、UseCases。
- 分析体验：SkinScanDemo、AnalysisMetrics、FaceMapping、PersonalizedRoutine。
- 转化内容：Pricing、FAQ、FinalCTA、Footer。
- 服务能力：上传、模拟报告、持久化、历史查询、错误处理。

## MVP 范围

当前 MVP 包含本地图片上传、基础文件校验、模拟美容护肤分析、SQLite 保存和查询。它用于展示产品体验与工程闭环，不评估真实皮肤状况。

## 当前不包含

真实 AI 推理、医学用途、账户与权限、跨设备历史中心、支付、会员、管理后台、云对象存储、生产监控和已完成的公网部署均不在当前版本中。

## 后续方向

依次完成腾讯云安全部署与公网联调，评估真实模型和数据治理方案，再建设用户系统、云存储、支付会员与运营后台。
