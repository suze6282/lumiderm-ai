# 安全与隐私

## 仓库规则

- 不提交 `.env`，只提交 `.env.example`。
- 不提交 SQLite / DB 文件、用户上传图片、测试上传图片、日志、`node_modules` 或 `dist`。
- 不提交 SSH 私钥、腾讯云 SecretId / SecretKey、Token、密码或服务器登录信息。
- 日志不得记录图片内容、完整个人标识、认证信息或密钥。

## 图片上传边界

当前 Multer 配置要求扩展名与 MIME 类型同时属于 JPG/JPEG、PNG、WEBP，并限制为 5 MiB。这个检查只能阻挡明显不匹配和超大文件，不能替代文件签名检查、图片解码重编码、恶意内容扫描、访问控制和速率限制。

`uploads/` 中的面部图片可能属于敏感个人数据。当前本地静态访问方式只适合开发；发布前应使用随机对象键、最小权限、鉴权或短期签名 URL，并禁止目录浏览。

## 模拟分析边界

当前报告由固定模拟模板生成，不使用真实 AI 模型，不评估疾病，也不构成医疗诊断或治疗建议。界面、API、文档和市场描述都必须保持这一边界。

## 数据保存与删除

当前 SQLite 记录和本地上传文件没有自动删除机制。生产化前必须确定最小化采集、明确同意、保存周期、用户删除请求、数据库与对象文件一致删除、备份保留和审计流程。

## 腾讯云 COS 建议

未来接入 COS 时，应使用子账号或角色的最小权限临时凭证，不把长期 Secret 写入前端或仓库；启用服务端加密、私有读、短期签名 URL、生命周期规则、跨域白名单、访问日志与异常告警。公开桶不适合存放用户面部图片。

## 生产化前最低补项

身份验证与授权、限流、安全响应头、可信代理配置、上传内容解码验证、病毒扫描策略、数据加密、日志脱敏、监控告警、备份恢复演练、隐私政策和数据删除机制均仍待完成。
