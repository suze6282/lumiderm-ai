# 腾讯云部署方案

## 当前状态

后端第 10—12 步尚未完成：没有已验证的腾讯云部署、生产安全配置或最终公网联调结果。以下内容是执行方案，不是成功记录。

## 安全边界

- 先对服务器、现有站点、Nginx、PM2、端口和证书做只读检查。
- 不覆盖旧网站目录，不删除旧 Nginx 配置，不复用现有 PM2 进程名。
- 不提交 SSH 私钥、腾讯云 SecretId / SecretKey、服务器密码或 `.env`。
- 安全组只按需要开放 22、80、443；SSH 最好进一步限制来源。
- Express 仅监听本机或由防火墙限制，3001 不直接暴露公网。

## 建议结构

- 独立部署目录，例如 `/var/www/lumiderm-ai/` 与 `/srv/lumiderm-ai-backend/`。
- 前端 `dist/` 由 Nginx 作为静态资源提供。
- 后端使用独立 PM2 名称，例如 `lumiderm-ai-api`。
- 使用独立 Nginx `server` 块；若必须共用域名，只新增明确的独立 `location`。
- `/api` 反向代理到 `127.0.0.1:3001`。
- `/uploads` 只在完成访问控制、缓存和隐私评估后开放；更推荐迁移到受控对象存储与签名 URL。

## 执行顺序

1. 只读记录现有域名、目录、PM2 列表、Nginx 配置、监听端口、磁盘和备份位置。
2. 为 LumiDerm 创建独立目录与最小权限运行用户，上传构建物和后端代码。
3. 在服务器独立创建 `.env`，把 `FRONTEND_ORIGIN` 设置为正式 HTTPS 域名。
4. 安装生产依赖，初始化独立数据目录，先在 `127.0.0.1:3001` 做健康检查。
5. 新建 PM2 进程并保存配置，不重启无关进程。
6. 新建并语法检查 Nginx 配置，确认无冲突后平滑 reload。
7. 配置 HTTPS、HSTS 策略评估、上传限制、安全响应头和日志脱敏。
8. 用正式域名验证 `/api/health`、上传、列表、详情和 CORS，再检查旧网站。

## 回滚

发布前备份新旧 Nginx 配置和 PM2 状态。出现问题时禁用 LumiDerm 独立配置、平滑 reload Nginx、停止独立 PM2 进程，并恢复备份；不删除或覆盖旧站点内容。数据库迁移前另行备份数据文件，回滚时不要把测试数据混入生产数据。

## 第 11—12 步验收重点

第 11 步应补齐生产 CORS、限流、安全头、上传内容验证、日志脱敏、数据生命周期、备份与监控。第 12 步再从公网执行 HTTPS、前后端联调、移动端、错误路径和回滚演练，并保存真实但不含秘密的验收证据。
