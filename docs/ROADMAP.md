# 路线图

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| Phase 1 | 高保真前端、响应式、动画与产品叙事 | 已完成 |
| Phase 2 | 后端 MVP 第 1—9 步：上传、模拟分析、SQLite、历史查询、错误处理 | 已完成 |
| Phase 3 | 腾讯云上线第 10—12 步：独立部署、安全配置、公网联调 | 待完成 |
| Phase 4 | 真实 AI 模型评估、数据集与推理服务 | 规划中 |
| Phase 5 | 用户系统、权限与历史中心 | 规划中 |
| Phase 6 | 云存储、支付、会员和管理后台 | 规划中 |

Phase 3 的完成条件包括：不影响旧网站、HTTPS、正式 CORS、3001 不暴露公网、上传与数据策略明确、回滚演练以及真实公网验收。Phase 4 只有在模型效果、偏差、隐私、合规与可解释性经过独立评估后才能改变“模拟分析”表述。
